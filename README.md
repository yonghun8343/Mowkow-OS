## Mowkow OS

> **머꼬 인터프리터와 GNU Nano가 내장된 32비트 교육용 운영체제**

Mowkow OS는 『OS 구조와 원리』를 기반으로 제작된 교육용 운영체제입니다.<br>
기본적인 커널 구조 위에 독자적인 한글 입력기를 구현하여 자유로운 한글 입출력이 가능합니다. <br>
부산대학교 우균 교수님이 개발한 한글 LIPS 머꼬 인터프리터를 내장하고 있습니다.

### 주요 기능

- 아키텍처: x86 32-bit 보호 모드
- 멀티태스킹: 라운드 로빈 스케줄링 기반의 멀티 윈도우 시스템
- 한글화:
    
    - 독자적으로 개발한 한글 오토마타 탑재 (두벌식 자판)
    - UTF-8 인코딩 지원
    - 둥근모꼴 비트맵 폰트 적용
- 파일 시스템: FAT12 플로피 디스크 + 파일 기술자를 통한 관리
- 응용 프로그램:

    - GNU Nano(나노)
    - 머꼬
    - 계산기

### 개발 환경

이 프로젝트는 Windows(WSL2) 환경에서 개발되었습니다.

- Wsl2: Ubuntu 24.04
- 에뮬레이터: QEMU
- 컴파일러: `CC1` (`gcc` 개량판)
- 어셈블러: `nask` (`nasm` 개량판)
- 빌드 도구: `make`

### 빌드 및 실행 방법

1. 현재 리포지토리를 로컬 저장소에 클론합니다.
2. 프로젝트의 최상위 디렉토리에서 터미널에 아래 명령어를 입력합니다.

    `make && make run`
3. 사용이 끝나면 qemu를 종료합니다.

### 단축키
`shift` + `space` : 한영 전환

`shift` + `F2` : 콘솔 열기

`ctrl` + `c` : 프로세스 강제 종료

### 명령어 목록

> 메모리 공간 조회
```bash
# 영어 명령어
> mem
# 한글 명령어
> 메모리
```

> 콘솔 창 지우기
```bash
# 영어 명령어
> clear
# 한글 명령어
> 지우기
```

> 파일 리스트 조회
```bash
# 영어 명령어
> ls
# 한글 명령어
> 목록
```

> 콘솔 종료
```bash
# 영어 명령어
> exit
# 한글 명령어
> 종료
```

> 애플리케이션 실행
```bash
# 현재 콘솔에서 실행
> <이름>

# 새 콘솔에서 실행
> start <이름>
> 실행 <이름>

# 새 콘솔에서 실행 후 콘솔 바로 닫기
> ncst <이름>
> 바로실행 <이름>
```

> 언어모드 전환(0: 영어, 1: 한글)
```bash
# 영어 명령어
> langmode <mode>
# 한글 명령어
> 언어 <모드>
```

### 사용하면서 발생될 수 있는 문제점

- 너무 많은 프로세스가 동시에 실행될 경우 그래픽이 깨질 수 있습니다.
가상환경을 껐다 켜주세요.

- 이 OS는 FAT12 플로피 디스크를 저장소로 사용합니다. 저장된 파일이 많아지면 OS 파일 시스템이 읽지 못할 수 있습니다. <br>
    또한 FAT12 파일 시스템 규격에 따라 파일 명을 다음 규칙에 맞게 작성해주십시오. <br>
    (파일 이름 8자 + 확장자 3자)
