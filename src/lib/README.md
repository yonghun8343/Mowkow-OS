# src/lib

```
│   └── 📂lib               # 라이브러리
│       ├── 📄fifo.c            # FIFO 버퍼
│       ├── 📄hangul.c          # 한글 입출력
│       ├── 📄tek.c             # tek 압축 해제
│       └── 📄utf8.c            # utf8 인코딩
```

커널에서 한글 입출력 및 데이터 송수신에 사용하는 라이브러리 코드입니다.

- `fifo.c` : 타이머/키보드/마우스 데이터 송수신과 태스크 데이터 임시 저장을 위한 FIFO 버퍼
- `hangul.c` : 한글 입출력 처리
- `tek.c` : tek 파일 압축 및 해제
- `utf8.c` : 한글 입출력 처리를 위한 uft-8 인코딩/디코딩
